# Ceylon Nooks: Milestone 2

Scope agreed on the 8 Oct call ($250, tools included): homepage redesign, checkout page, category template page, travel tools pages, and listing page fixes (cancellation options, photo gallery, trust badges).

**Open `Ceylon-Homepage.html`** to view the homepage. It's a single file with the photos embedded. `homepage.html` is the editable source and uses the photos in `../ceylon-traveller-dashboard/img/`.

## Homepage, first draft (9 Oct)

What Akila asked for on the call, and where it is:

| From the call | On the homepage |
| --- | --- |
| Modern and friendly, to build trust for international payments | Hero with real photos, a host chat preview and a price chip that says taxes and fees are included. Same Inter type, orange and site header as the dashboard |
| Search tours and activities separately | Search has **Tours** and **Activities** tabs, each with its own popular shortcuts |
| Stays and transport shown as coming, not clickable | A **What's next** section with two cards labelled "Coming soon": Stays, and Transport (taxis, car hire with or without a driver). They aren't in the search |
| Links to inner pages for attractions and destinations | **Popular attractions** grid and a **Place to go** island map with destinations; each links to its inner page |
| Show the latest categories and listings | **Tours or activities?** category block (links to the category template page) and **Just listed** cards |
| No hidden fees | Trust bar, plus a panel with a real price breakdown: one total, details on demand |
| Chat with providers before booking | Trust bar, plus a panel with a sample chat with a licensed host |
| Helpful tools on their own pages | **Free travel tools**: Trip planner, Visa checker, Traveller quiz, Travel time estimator, Best time to visit, Last-minute checklist, with a link to the tools page |
| Invite service providers | **For guides, drivers and hosts** section |
| Text for search engines without cluttering the page | **Tours and activities in Sri Lanka** block with a "Read more" toggle |

Placeholders until Akila sends them: the logo file, his homepage layout concept, the final list of attractions, destinations and categories, and the tools to build first. Listings, counts and ratings are sample content. Photos are Creative Commons stand-ins (credits in the dashboard README).
