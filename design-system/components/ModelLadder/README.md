# ModelLadder

"What each model adds to the one below it": eight rungs in ascending order. Rungs that add capability have a solid `sun` edge and a filled background; the three "same capability, bigger battery" models (1900, 3100, 8000) use `.lm-same`: indented, dashed edge, no fill. That visual difference is the point of the section.

The consumer provides an `<ol>` of rungs from the product source, each with the name, box-only price and one sentence starting "Adds:" or "Nothing new".
