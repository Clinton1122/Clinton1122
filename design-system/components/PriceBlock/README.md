# PriceBlock

The price block inside a product hero. A two-option toggle (box only / box plus panels) switches the big price and the pre-filled WhatsApp message; it's the "variant selector" borrowed from the Thrillhouse and Letsgosolar references.

Both prices are in the HTML and in the Product schema as two Offers; the toggle only changes which one is shown large. Without JavaScript, show both lines stacked. The consumer provides the two prices, the panel description and the WhatsApp link.

On mobile this block must sit above the fold: gallery, H1, price block.
