# Footer

Global, on `surface-inverse`: a brand column and four link columns (Products, Buy & Own, Support, Company), a full-width contact block for both offices, and the legal bar. Column headings use `label` in `sun`.

Every link must resolve; the old footer had three dead ones. Addresses and numbers come from the single site-facts source that also feeds `/contact`, `/where-to-buy` and the LocalBusiness schema. Columns go 5 → 2 → 1 as the width drops.
