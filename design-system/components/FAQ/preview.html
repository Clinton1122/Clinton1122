Do I still need an inverter if I buy a PowerBox?

No. The inverter is already inside. A Lumey PowerBox contains a hybrid pure sine wave inverter, a lithium battery, a charge controller and a protection system in one unit.

Can I charge it with NEPA?

Yes. Every PowerBox charges three ways: from solar panels, from a wall socket, or from grid power when it is available.

Can it run my air conditioner?

Only the heavy-duty range. The PowerBox 4000 and 8000 run one inverter AC, best during the day with panels connected.
