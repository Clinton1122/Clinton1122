# FAQ

Accordion built on native `<details>`/`<summary>`, so every answer is in the HTML whether open or closed. That is a hard PRD requirement: answers hidden by CSS, never injected on click, because this block is what search engines and AI answer engines quote.

First item open by default. Desktop: two columns of questions; mobile: one. The consumer provides the question as the summary and the answer, first sentence answering directly, plus matching FAQPage schema.
