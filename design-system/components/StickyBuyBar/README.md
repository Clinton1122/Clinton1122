# StickyBuyBar

Appears on product pages once the hero scrolls out of view: model name, both prices, an instalments link and the WhatsApp order button. `surface-inverse` with a 2px `sun` top edge and `shadow-float`; fixed to the bottom and lifted by the safe-area inset.

On mobile it keeps only the name, the box price and the button. It must not cover the floating WhatsApp button; when the bar is showing, hide the floating button. The PowerBox 2600 page gets the most prominent version (the PRD's volume model).
