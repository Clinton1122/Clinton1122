# ProductRow

One model in the series listings (products hub sections 4 and 5, series pages): a 45/55 image and copy split, alternating sides with `.lm-flip`.

The price sits on the same line as the model name, never below the card's fold. "Best for" and "Not for" are a definition list; "Not for" is in `ink-muted` so the limits read as honest, not hidden. On mobile the order is image, name and price, body, best for / not for, CTA.

The consumer provides the model data from the single product source and the product photo (three-quarter studio shot, same angle for the whole series).
