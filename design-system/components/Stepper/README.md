# Stepper

Numbered steps for real sequences: setup, ordering, delivery, how to apply. The numbers come from a CSS counter in yellow discs, so the steps are a plain `<ol>` (HowTo schema maps onto it directly).

Horizontal on desktop, vertical on mobile (the grid wraps). The consumer provides an `<ol class="lm-steps">` of `<li>` each holding an H3 and a sentence or two. Works on `surface` and `surface-inverse`.
