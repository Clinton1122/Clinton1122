# ProblemCard

The homepage "problem" cards. The PRD rules out icons here ("icons make a serious problem look like a feature list") and asks for a large numeral instead: `.lm-problem-num` in `display` at 125% width, coloured `sun-ink`.

`surface-alt` fill with a hairline top border, no shadow. Stack full-width on mobile. The consumer provides the numeral, an H3 and one short paragraph. Use exactly three; the numbering is for these three cards only.
