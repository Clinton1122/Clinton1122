# FeatureCard

Black cards with yellow headings on a white section: "Why Lumey", "The same promises on every model", "After you buy it". `surface-inverse` fill, square corners, H3 in `sun`, body in `ink-inverse-muted`.

The consumer provides an H3 and a short paragraph, optionally followed by a `.lm-link` on the inverse ground. Use in grids of 2, 3 or 4, never with a single card.
