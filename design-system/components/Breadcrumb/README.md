# Breadcrumb

The trail at the top of every product, series and support page (Home → Products → Portable Series → PowerBox 2600). It must match the page's BreadcrumbList schema exactly.

The consumer provides an `<ol>` of links, the last item a `<span aria-current="page">`. Works on any ground; separators take `ink-muted` or `ink-inverse-muted`.
