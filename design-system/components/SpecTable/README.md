# SpecTable

The full specification on each product page: label in body weight 600, value in `spec` (mono), hairline rows.

A value that is not confirmed yet shows "To be confirmed" in `.lm-pending` rather than an empty cell; the PRD's spec sheet still has 13 blank rows per model. Each row also maps to a Product `additionalProperty` in schema. The consumer provides rows from the product source.
