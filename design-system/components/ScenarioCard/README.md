# ScenarioCard

"Who it's for" cards: a real photograph, the setting, what runs, and a "Start with:" line linking to the right model.

The photo slot is 4:3 and must be a real Lumey customer setting (the PRD's IMG-05 to IMG-10). Until the photo exists, the slot shows its filename; never fill it with stock. Desktop: horizontal scroll with snap; mobile: 2-column grid.
