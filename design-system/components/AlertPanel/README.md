# AlertPanel

The one strong warning on the site: the safety panel at the top of `/support/troubleshooting`. `alert-soft` fill, 2px `alert` border, a square "!" marker. The warning is carried by the words and the marker, not by colour alone.

Use `alert` for nothing else except form errors. The consumer provides the title, the list of symptoms and the support number as selectable text with a tap-to-call link.
