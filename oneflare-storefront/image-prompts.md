# Oneflare — Image shot list & prompts (Templates 02 Studio · 03 Noir)

Every placeholder in Figma is a layer named `ph/<id>`. The IDs below match those layer names exactly.
Where the same product appears in several places (card, bag line, "complete the look"), **one image covers all of them** — the list tells you which layers to fill with it.

**Totals:** 25 images for Studio (S1–S25) · 18 images for Noir (N1–N18) · 43 in all.

---

## Rules for every image (apply to all 43)

- **No text, no logos, no watermarks, no brand labels** on clothes, packaging or backgrounds. Oneflare's logo is added by the design, never baked into the photo.
- **Models:** Nigerian / West African, natural skin texture (no plastic retouching), natural hair, relaxed confident expression, never smiling at camera like stock.
- **Colour:** muted and true-to-fabric. No neon, no heavy filters, no teal-and-orange grading. The templates are monochrome — the photos carry the only colour.
- **Generate at the pixel size given** (2× the Figma size) or larger with the same aspect ratio. In Figma, select the `ph/` layer → Fill → Image → **Fill** mode.
- **Consistency:** generate each template's product shots in one session with the same seed / style reference so light and backdrop match across the grid.
- **Negative prompt (paste into every generation that supports one):**
  `text, letters, logo, watermark, signature, brand label, extra fingers, distorted hands, warped fabric, plastic skin, oversaturated, neon, HDR, lens flare, busy background, props clutter, visible mannequin, cartoon, illustration, 3D render`
