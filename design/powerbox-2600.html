Questions about the 2600

Can the PowerBox 2600 run a freezer?

Yes. A chest freezer or a full double-door fridge runs on it; it is the smallest PowerBox that does. Size for the freezer running all night, because it keeps cycling while you sleep.

Can it run a microwave?

Yes, within its 2kW rating. Avoid running the microwave at the same moment as the induction cooker or a kettle.

Can it run an air conditioner?

No. Air conditioning starts with the PowerBox 4000, which runs one inverter AC on a 4kW (5kVA) inverter.

How long does it last on a full charge?

It depends on what you run. Divide 2,600 by your total load in watts for a rough number of hours, then allow for losses. Measured run-times will be published here.

Is it heavy?

Heavier than the smaller models; most people set it down once and leave it. If you're on an upper floor, say so when you order so delivery comes prepared.
