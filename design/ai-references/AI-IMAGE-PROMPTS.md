# Lumey website: AI image prompts

Every image slot in the Figma file (page "new direction"), with a copy-paste prompt for each.
Each prompt already includes the PowerBox description and the photo style, so it works on its own.

## How to get the PowerBox right

1. Attach real photos as reference images (folder `1-product-cutouts-transparent`):
   - `powerbox-front-two-displays_LEH_2745.png`: front view (2600-style box).
   - `powerbox-three-quarter-side-ports_LEH_2747.png`: three-quarter view showing the side ports.
   - For scenes with several sizes: `powerbox-family-three-sizes_LEH_2769.png`.
2. Tell the tool to keep the product exactly as in the reference: same colours, panel layout, fan grille and strap.
3. Generate large (at least 2000px on the long side) in the aspect ratio listed, so Figma can crop it cleanly.
4. If a person's hands or the box look wrong, regenerate. Do not use an image with a distorted product.

Note: which photo shows which model (600, 1500, 1900, 2600, 3100) is my best match by size and panel layout.
Please confirm with the team.
